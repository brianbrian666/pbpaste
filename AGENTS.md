# AGENTS.md

## Project Overview

An original macOS clipboard manager (menu bar utility): polls the pasteboard, stores text/image/file history in SwiftData, and shows a floating panel via a user-configurable global hotkey (default ⇧⌘V). Clean-room implementation — no code or assets from any commercial clipboard manager.

- macOS-only (`SUPPORTED_PLATFORMS = macosx`), deployment target 27.0, Swift 5 language mode.
- App is a menu bar agent: `INFOPLIST_KEY_LSUIElement = YES`, no Dock icon.
- App Sandbox is **disabled** (`ENABLE_APP_SANDBOX = NO`) so the Accessibility grant can authorize CGEvent ⌘V posting for auto-paste. Do not re-enable it without removing auto-paste.
- Bundle ID: `devplaceholder.LBD425YC.pbpaste`; product name `pbpaste` (UserDefaults domain `devplaceholder.LBD425YC.pbpaste`). Ad-hoc signing invalidates the Accessibility grant and iCloud entitlement on every rebuild.
- Not a git repository.

## Build

`xcodebuild` fails out of the box because `xcode-select` points at the Command Line Tools. Either prefix with `DEVELOPER_DIR` or run `sudo xcode-select -s /Applications/Xcode.app/Contents/Developer`.

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
  xcodebuild -project paste.xcodeproj -scheme paste \
  -destination 'platform=macOS' -derivedDataPath build build
```

Project is `paste.xcodeproj`; scheme and target are both `paste`; product is `pbpaste.app`. `build/` holds derived data (contains stale artifacts from the pre-rename `Untitled Project` / `MyApp` builds). Run the app: `open "build/Build/Products/Debug/pbpaste.app"`. Kill it: `pkill -x pbpaste`.

Packaging for local install/distribution (ad-hoc signed, no Apple certificates in the keychain):

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
  xcodebuild -project paste.xcodeproj -scheme paste -configuration Release \
  -destination 'platform=macOS' -derivedDataPath build build
mkdir -p dist && cp -R build/Build/Products/Release/pbpaste.app dist/
# optional DMG: stage the app + an /Applications symlink, then hdiutil create -volname pbpaste -srcfolder <staging> -ov -format UDZO dist/pbpaste-1.0.dmg
```

The ad-hoc signature means `spctl` rejects the bundle and every rebuild invalidates the Accessibility grant — the user must re-grant after installing a new build. Locally built copies carry no quarantine attribute, so they launch without Gatekeeper prompts; a DMG shared to another Mac needs right-click → Open (or `xattr -d com.apple.quarantine`).

## Architecture

`paste/` is a `PBXFileSystemSynchronizedRootGroup`: files added/removed on disk are picked up automatically. Never edit `project.pbxproj` to add a source file.

- `MyApp.swift` — `@main` App (struct `MyApp`), `@NSApplicationDelegateAdaptor`, `Settings { EmptyView() }` placeholder scene. The scene injects an empty ⌘, item into the main menu on activation; `AppDelegate.scrubAutoSettingsMenuItem()` removes it so only the status-item entry opens the real preferences window.
- `AppDelegate.swift` — composition root: status item + menu (show, pause, accessibility-permission state, launch-at-login, clear, settings ⌘,, quit), starts the monitor, registers the hotkey, owns preference keys (`PreferenceKeys`: `hotkeyCode`, `hotkeyModifiers`, `retention`, `useICloudStorage`, `lastStoreLocation`), shows the preferences window (`showPreferences`).
- `Model/` — `ClipItem` (@Model: kind/text/rtfData/imageData(.externalStorage)/fileURLStrings/contentHash/isPinned/source app, search matching), `ClipPayload` (pasteboard reading, SHA-256 content hash, ignored-type filtering: ConcealedType/TransientType/AutoGeneratedType/1Password).
- `Store/ClipboardStore.swift` — ModelContainer at a resolved `StoreLocation` (see below); dedup (same hash → bump `createdAt` to move to top, pinned items keep their place), pin toggle, `maxUnpinnedItems = 300` prune, clear-unpinned, `pruneRetentionIfNeeded()` (unpinned items older than the `retention` pref; pinned exempt; "forever" is a no-op; runs at launch, on insert, and when the pref changes). Exposes `usingICloud` / `iCloudContainerAvailable`.
- `Store/StoreLocation.swift` — where the SQLite store lives: `~/Library/Application Support/pbpaste/clips.store` (local) or the iCloud container's Documents (only when the `useICloudStorage` pref is on **and** the container exists — ad-hoc builds have no iCloud entitlement, so it always falls back to local silently). `migrateIfNeeded(to:)` runs **before** the ModelContainer opens and follows `lastStoreLocation` lineage: copy `.clips_SUPPORT/` → `-wal` → `clips.store` **last** (completion marker; skip `-shm`), never delete the source. It also performs the one-time legacy move from the old `MyApp` directory (source left in place as backup).
- `Store/RetentionPeriod.swift` — `forever` / `1d` / `7d` / `30d` retention pref (UserDefaults string) with `cutoff: Date?`.
- `Clipboard/` — `ClipboardMonitor` (changeCount polling 0.4 s on RunLoop `.common`; call `acknowledgeOwnWrite()` after any self-initiated pasteboard write or the app will capture its own paste), `PasteboardWriter` (rich text = RTF + string; ⌥-paste writes string only), `Paster` (Accessibility check, CGEvent ⌘V).
- `Hotkey/KeyCombo.swift` — persisted hotkey (keyCode + Carbon modifiers, default ⇧⌘V). Persistence uses `object(forKey:)` presence checks, never `integer != 0` (keyCode 0 is valid). `displayString` renders via `UCKeyTranslate` on the current input source, cached per layout — the combo is layout-agnostic, only the label follows the layout.
- `Hotkey/GlobalHotkey.swift` — Carbon `RegisterEventHotKey`. Single shared instance: init unconditionally installs a global EventHandler, so re-registration goes through `update(keyCode:modifiers:)` (re-register old combo on failure) and recording uses `suspendRegistration()` / `resumeRegistration()` — never construct a second instance. Handler bridges to the main actor via `MainActor.assumeIsolated`, which is safe because Carbon dispatches on the main thread.
- `Settings/` — `HotkeyRecorder.swift` (NSView recorder: ⎋/bare-⌫ cancel, bare-Tab swallowed, requires ⌘/⌃/⌥ or F1-F19; AppDelegate suspends the hotkey while recording), `PreferencesView.swift` (hotkey / retention picker / iCloud toggle + footnote + restart alert), `PreferencesWindowController.swift` (singleton window, `NSHostingView` with `sizingOptions = []`, resumes the hotkey on close), `Relauncher.swift` (restarts via `Process` + `Bundle.main.executableURL` — bare `open` would only activate the running instance).
- `Panel/` — `PanelMetrics` (single source of truth for card/strip/panel geometry: 198×270 cards, panel spans the mouse screen's full `visibleFrame` width edge-to-edge, `panelFrame(for:)` bottom-anchored), `HistoryPanel` (borderless non-activating NSPanel, `level = .statusBar`, key-status allowed, **intercepts plain ←→↑↓/↩/⌥↩/⎋ in `sendEvent` before the search field's field editor sees them** — modified arrows and ⌘/⌃+↩ pass through so caret/word editing still works), `PanelController` (sizes the tray to the mouse screen's visibleFrame on every show, paste orchestration, `KeyCommandRelay`; posts `.clipPanelDidShow` on show and on becomeKey so `HistoryView` resets the search text and time filter and refocuses the field; **hides on resign-key only after a 0.25 s debounce** — front apps with an active IME composition yank key status back the instant the panel takes it, and an instant hide would make the panel flash closed). Clicking a card always pastes: the pasteboard is written, the panel hides, and the synthetic ⌘V fires after 0.12 s — if Accessibility is not granted, the item is still copied and an alert (throttled to one per 30 s) points at System Settings.
- `UI/` — `HistoryView` (@Query, search, `PanelListModel`; bottom-anchored horizontal `ScrollView`+`LazyHStack` card strip, centered when the cards fit; clock menu in the search bar switches `PanelListModel.timeFilter`), `TimeFilter.swift` (`all` / `lastHour` / `today` / `last7Days`, display-only filter over the fetched items, reset to `all` every time the panel shows), `ItemCard` (198×270 card: preview area with in-card image thumbnail — image-kind clips use stored data, files-kind clips whose first URL decodes (image/PDF) get a file thumbnail before falling back to the file-icon placeholder; pin badge, selected/hover styling, source app icon + relative time), `ThumbnailCache` (ImageIO downsample at decode time + `NSCache` keyed by `contentHash` for image data and by path for file URLs; also header-only pixel sizes).
- `Localizable.xcstrings` — String Catalog, English source + zh-Hans; UI language follows the system. Non-`Text` literals must use `String(localized:)` explicitly — `Text(cond ? "A" : "B")` binds the `String` overload and does **not** localize.

## Conventions and Quirks

- Swift 5 mode, but `SWIFT_DEFAULT_ACTOR_ISOLATION = MainActor`: types are implicitly `@MainActor` unless marked otherwise. Carbon C callbacks and Timer closures need `MainActor.assumeIsolated`.
- `Foundation.SortDescriptor` cannot sort by `Bool` keypaths for non-NSObject types — pinned-first ordering is done in `PanelListModel.filteredItems`, not in the `@Query` (query sorts by `createdAt` only).
- Reads of AppKit/iOS-only frameworks require explicit imports even for member access (`import SwiftData` for `.modelContainer`, `import Carbon.HIToolbox` for `kVK_ANSI_V`).
- Auto-paste and Accessibility: check `AXIsProcessTrusted()` live on every paste; ad-hoc signing invalidates grants on rebuild, so the item is degraded to clipboard-only, the status-menu "Accessibility Permission" item shows the grant state, and the paste alert re-prompts (30 s throttle) pointing at System Settings. When auto-pasting, `PanelController.performPaste` waits 0.12 s after hiding the panel before posting the synthetic ⌘V, so the previously focused app has regained key status.
- Carbon `RegisterEventHotKey` is non-exclusive: with two instances running (e.g. an Xcode-run Debug copy plus an installed build), the later registrant receives the events, and after that instance dies the earlier one does **not** reliably resume — relaunch the surviving instance. Never run two copies at once when testing the hotkey.
- `ENABLE_PREVIEWS = YES` — keep `#Preview` blocks compiling when changing views.

## Testing

Headless smoke test (what is automatable):

```sh
printf 'test text' | pbcopy; sleep 1   # capture
sqlite3 ~/Library/"Application Support"/pbpaste/clips.store \
  "SELECT ZTEXT, ZKIND, ZISPINNED FROM ZCLIPITEM ORDER BY ZCREATEDAT DESC;"
```

Prefs live in the `devplaceholder.LBD425YC.pbpaste` domain, e.g. `defaults write devplaceholder.LBD425YC.pbpaste retention -string "1d"`. `ZCREATEDAT` is Core Data's 2001-epoch seconds: `unix_seconds − 978307200`. **Always `pkill -x pbpaste` before editing the sqlite store or defaults** — the app holds the store in WAL mode and caches rows.

To write non-text pasteboard content (files, images, concealed types), use a small `swift` script at `/Applications/Xcode.app/Contents/Developer/Toolchains/XcodeDefault.xctoolchain/usr/bin/swift` with `NSPasteboard`/`declareTypes`. Note: such tests clobber the user's clipboard.

Needs a human at the machine: the default ⇧⌘V hotkey and recording a new one in Settings (bare keys must beep, F-keys accepted, ⎋ cancels), search-field focus/typing in the non-activating panel, ←→/↑↓ selection (⌥←/⌥→ must still move the caret in the search field), ↩/⌥↩/⎋ keys, picking a time filter from the clock menu, the card strip's bottom-center placement and image thumbnails, click-to-paste into another app (with and without the Accessibility grant), login-item toggle, multi-display positioning.
